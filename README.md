# Violet Cosmos — Anushka Choubey Portfolio

This package preserves the original portfolio source and visual atmosphere. The active browser entry is `src/main.js` (vanilla JavaScript); `src/main.jsx` is retained unchanged as part of the original project source. The original mist, falling petals, audio, scene backgrounds, Shinobu artwork, project details and navigation are preserved.

## Run locally

Requirements: Node.js and Python 3.

```bash
npm install
npm run dev
```

Open http://localhost:4173. The `dev` script rebuilds `dist/` and serves it.

## Build

```bash
npm run build
npm run preview
```

The build copies `src/`, `public/`, audio, images and resume assets into `dist/`.
